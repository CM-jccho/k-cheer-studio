# K-Cheer Studio

콘서트 응원 슬로건, 투명 포토카드 프레임, 기념 티켓을 만들어 인쇄용 PNG와 PDF로 저장하는 정적 웹앱입니다.
스페인어, 포르투갈어, 영어, 한국어 네 가지로 동작하고, 빌드 도구나 서버 없이 폴더를 그대로 올리면 됩니다.

## 폴더

```
index.html            화면 한 장
css/tokens.css        색, 글자 크기, 여백 토큰
css/app.css           스타일 (첫 줄에 Hallmark 스탬프)
js/config.js          상점 정보, 라이선스 코드, 출력 크기
js/i18n.js            네 개 국어 문구
js/frames.js          포토카드 프레임 20종 벡터 드로잉
js/render.js          슬로건, 포토카드, 티켓 렌더러와 PDF 작성기
js/app.js             화면 상태와 다운로드
assets/fonts/         Pretendard, Archivo Black (앱에 함께 들어 있음)
tests/                Playwright 검증 스크립트
tools/                프레임 PNG와 인쇄 가이드 PDF를 만드는 스크립트
```

## 호스팅

정적 호스팅이면 어디든 됩니다. 폴더를 그대로 올리면 끝입니다.

- GitHub Pages: 저장소 루트에 이 폴더의 내용을 올리고 Pages를 켭니다
- Vercel, Netlify: 프레임워크 없이 정적 사이트로 배포합니다
- 로컬 확인: `python3 -m http.server 8080` 후 http://localhost:8080

외부 요청이나 계정 로그인이 없습니다. 사진과 문구는 브라우저 안에서만 처리되고 서버로 보내지 않습니다.

## 상점 설정

`js/config.js`에서 고칩니다.

- `proBuyUrl`: Gumroad 상품 주소. 비워 두면 화면에 "상점 링크는 아직 연결하지 않았습니다"가 나옵니다.
- `proPrice`: 상단 바에 보이는 가격.
- `licenceHashes`: 구매자에게 주는 코드 목록. 화면에는 절대 출력되지 않고, 입력값을 해시로 바꿔 비교합니다.
- `sizes`: 출력 크기(mm). 슬로건 600 × 200, 포토카드 55 × 85, 티켓 180 × 70, 리본 60 × 240.
- `dpi`: 무료 150, Pro 300.

## 무료와 Pro

| | 무료 | Pro |
| --- | --- | --- |
| 프레임 | 기본 4종 (Star, Ribbon, Checker, Polaroid) | 20종 전부 |
| 출력 | 150 dpi | 300 dpi |
| 하단 표기 | 들어감 | 없음 |
| Pro 팩 | | Gumroad에서 판매하는 프레임 PNG 20종, 인쇄 가이드 PDF |

Pro는 코드를 넣으면 그 브라우저에 기억됩니다(localStorage).

## 출력 규격

| 모드 | 크기 | 무료 | Pro |
| --- | --- | --- | --- |
| 응원 슬로건 | 600 × 200 mm | 3543 × 1181 px | 7087 × 2362 px |
| 포토카드 | 55 × 85 mm | 325 × 502 px | 650 × 1004 px |
| 티켓 | 180 × 70 mm | 1063 × 413 px | 2126 × 827 px |
| 리본 | 60 × 240 mm | 354 × 1417 px | 709 × 2835 px |

PDF는 슬로건에서만 나오고 A3 가로 한 장으로 저장됩니다. 이미지를 JPEG로 넣어 인쇄소에서 바로 열 수 있습니다.

## 검증

```
python3 tests/e2e.py
```

64개 항목을 확인합니다. 네 개 국어 키 누락, 세 모드 렌더링, 무료와 Pro 다운로드 크기, 포토카드 알파 채널,
잘못된 코드 거부, 320에서 1920까지 가로 스크롤 없음, 콘솔 오류 없음.

## 대량 제작

```
python3 tools/build_pack.py
```

프레임 PNG 20장, 인쇄 가이드 PDF, `downloads/` 아래의 두 ZIP을 다시 만듭니다.

## 법적 안전

아이돌, 그룹, 멤버, 소속사 이름과 공식 응원봉 모양, 가사, 로고를 쓰지 않습니다.
문구는 팬이 직접 입력하고, 예시 문구도 일반적인 응원 표현만 넣었습니다.
프레임 20종은 이 앱을 위해 그린 오리지널 벡터입니다.
